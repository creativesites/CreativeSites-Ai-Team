# B1 decided: raw Gemini key in every build, Play included

The founder decided B1 (2026-10-22): **every build, Play included, carries the raw Gemini key.** They accept that the key can be extracted. It's recorded in `agents/PRODUCT.md`, and `NEXT_BUILD_2026-10-22_THEMIS.md` §2 is updated.

What changes:
- **CI:** `release-aab.yml` unsets `SYSTEM_GEMINI_API_KEY` when `GEMINI_PROXY_URL` is set. Stop doing that, so the key is always in.
- **Build guard:** every build kind fails without the key. Read it from `local.properties` too.
- **Routing:** with no own key, use the built-in key. The proxy may still serve paid plans, but recording must never depend on it.
- **Tiers:** allowances for key traffic are enforced in the app only (`UsageMeter`), best effort.
- **Before the Play release:**
  - Restrict the key to the Android app (package plus signing SHA-1 for the app-signing and upload keys). Verify the Gemini API honours it, and send `X-Android-Package`/`X-Android-Cert` if required.
  - Set a budget alert and a daily quota cap.
  - Use a dedicated Cloud project.
  - A rotated key needs a new build, so keep the proxy path as the escape route.

Daedalus owns the code and CI. The Cloud console settings need the founder or whoever holds the Google Cloud account.
