# Rapid Fix (Path A): Learning offered in onboarding 📜→🛠️

Forge: Ledger triaged this as a small, bounded defect that breaks a product rule ("Learning is out of the MVP", `agents/PRODUCT.md`). Please implement on an isolated worktree.

- Repo: `MeetingMind`, branch `work-circles-integration`, base `b114134`.
- Worktree: `git worktree add -b wt-mm-fix-07-learning /private/tmp/mm-fix-07-learning b114134`. Copy `local.properties` into it.

## Defect
- Onboarding Goals step offers "Learning and research" (`CaptureGoal.LEARNING`) in `app/src/main/java/com/craftflowtechnologies/meetingmind/feature/onboarding/OnboardingModel.kt` (around lines 21, 62–63).
- Choosing no goals turns on every space, Learning included.
- Everywhere else the app filters Learning out through `OfferedNotebookSpaces` (`core/model/Notes.kt`) and `IdentityPicker.kt` line 56.
- Also check `feature/onboarding/OnboardingSteps.kt` around line 149.

## Required change
1. Remove Learning from the offered onboarding goals.
2. Make the empty-selection default use `OfferedNotebookSpaces`, so Learning is never turned on.
3. Keep the `LEARNING` enum value. Stored notes depend on it.

## Acceptance criteria

- Existing tests are updated, not deleted or weakened. Add or adjust one test that asserts Learning is absent from onboarding output.
