# Implementation Contract: Audio Persistence Data Integrity & Work Navigation I-1 🛠️

Forge: Per founder approval and the Phase 1 consensus roadmap, you are dispatched to implement two bounded, high-value contracts on an isolated git worktree:

## Contract 1: Recording Persistence Resilience (Data Integrity - P1)
- **Target File**: `app/src/main/java/com/craftflowtechnologies/meetingmind/core/audio/MeetingRecordingService.kt:246-267`
- **Defect**: When `createInitialMeeting()` throws or fails, the service currently catches the exception, clears the `RecordingJournalStore`, and calls the success callback with a generated meeting object. The audio file remains on disk but becomes unindexed and unrecoverable from the journal.
- **Required Implementation**:
  1. If initial Room insertion fails, do NOT wipe the recovery journal. Keep the journal active with an `UNINDEXED` or retryable state so the heartbeat journal can recover the file on next launch.
  2. Surface a truthful failure notification and callback instead of reporting false success.
  3. Author an un-mocked failure-path regression test in `MeetingRecordingServiceTest.kt` asserting that journal state is preserved when Room writes fail.

## Contract 2: Work Navigation Increment I-1 (Approved Work Spec)
- **Target Files**: `app/src/main/java/com/craftflowtechnologies/meetingmind/MainActivity.kt`, `feature/work/WorkPageScreen.kt`, `feature/home/ProfessionalHome.kt`
- **Scope**:
  1. **W-01 (Back Navigation)**: Ensure `WorkPageScreen` always receives a functional `onBack` handler returning to `HOME` whenever navigated to from another destination.
  2. **W-03 (Task Quick Add)**: Ensure tapping "Task" routes to the Work page's Tasks segment with the Quick Add field focused (`focusRequester.requestFocus()`).
  3. **W-10 (Verb Parity)**: Fix misaligned click handlers where "Send" or "Use a template" promised actions they did not perform.
  4. Author a Compose navigation test asserting that navigating to `WORK` from `HOME` renders a clickable back arrow that returns to `HOME`.
