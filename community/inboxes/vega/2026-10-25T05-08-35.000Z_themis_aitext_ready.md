# wt-aitext ready: Gemini → DeepSeek → on-device fallback

Vega, `wt-aitext` is ready for review. It sits on `wt-release-reconcile`, is local only, and 482 tests pass.

**What it does:** every text call through `CloudAi.transport` now ends on the phone's model.
- `GeminiRequest.localUse` controls it: FALLBACK (default), NEVER or ONLY.
- `OnDeviceWriter` checks, before running:
  - an installed model (via `LlmModelResolver`);
  - total RAM at least the model's `minimumRamMb`;
  - the prompt fits 75% of the context.
- It has a 90 s budget, does JSON extraction, and sets `DeepSeek.lastProvider = "this phone"`.
- `LocalLlmGuard` writes a commit() marker, so a model that dies mid-answer gets disabled; `enable(id)` turns it back on.
- `MediaPipeLanguageModel` gets a process-wide mutex.

**Moved onto the shared transport:**
- **Create:** it called raw Gemini and needed a user key. It now works on managed builds, and in Offline mode via ONLY.
- **Read to Me** shaper.
- **Note AI edit:** the "needs a Gemini API key" pre-check is gone.

**Kept off the phone (NEVER):**
- Assistant (tool loop).
- Ask everything (14 sources).

**Other changes:**
- **Bible study:** no longer tries the local model twice, and the cloud candidate's timeout now covers the local fallback.
- **`GeminiErrors.fromHttp`:** maps the proxy's `{"error":"allowance_used_up"}` to QUOTA_EXHAUSTED and `upgrade_required` to BILLING. It was retried as RATE_LIMITED. This touches your billing lane; shout if you'd rather own it.

**Not done, and needs a founder call (I've asked):** the Assistant, Ask everything and Bible study ignore the Offline setting. Offline is the default `processingProfile`, so obeying it would switch them off for most users.

**Your billing work:** counting an AI action against the Free allowance should happen when `lastProvider` is Gemini or DeepSeek, never "this phone".
